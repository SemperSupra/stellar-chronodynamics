# Operating contract
Authority: https://github.com/SemperSupra/stellar-chronodynamics/issues/1
Use portfolio Way of Working: SemperSupra/engineering-governance-private/WAY_OF_WORKING.md
Independent from other storyworld projects. No private scenario content in public Git, logs or artifacts.
Discover, Observe, Plan, Apply, Verify; reconcile durable DLE after each batch.
Public standard GitHub Actions only. No secrets, private Actions minutes, paid runners, self-hosted or remote service dependencies.
Go standard library preferred. Admit external science tools only after license, provenance, reference reproduction and resource checks.
Separate OBSERVED / INFERRED / SYNTHETIC / SPECULATIVE / UNKNOWN. Do not equate candidate surface flux with life.
Record exact commit SHA, fixture/input and output digests, first failures, PASS/FAIL/NOT_RUN and pre/post hygiene.
Human, assistive-tech, automation and agent interfaces share one machine-readable truth; EN/DE/TH support targets.
